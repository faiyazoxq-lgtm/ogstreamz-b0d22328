---
name: VIP tone and terminology
description: How to refer to and address VIP / Real OG users across all copy, AI replies, and notifications
type: preference
---
**Synonyms (interchangeable, all = same tier):** VIP, VIP pass holders, Real OG, OG, OGs, Real OGs.

**Tone rules for anyone in this tier:**
- Treat with street OG respect at all times.
- Never swear at them, never roast them, never use the rougher "house" voice.
- Make them feel like an OG — acknowledged, respected, top-shelf.
- Free / non-VIP users may receive the harsher / sweary tone (per existing civility settings), but VIPs are always exempt.

**How to apply:**
- Any AI persona, system prompt, notification, or UI copy that addresses the user must check VIP status and switch to respectful OG-tone for VIPs.
- When writing new flows that talk to the user, default the VIP variant to no profanity and warm/respectful framing.
